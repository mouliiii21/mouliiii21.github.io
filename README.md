Static site with no framework and no build step. Projects and skills are rendered from `data.js`.

### `## run locally`

```bash
git clone https://github.com/mouliiii21/mouliiii21.github.io.git
cd mouliiii21.github.io
python -m http.server 8000
```

Then open http://localhost:8000.

### `## structure`

```
index.html   page layout and content
style.css    theme, layout, animations
script.js    rendering, typing effect, scroll reveal
data.js      projects and skills
resume.pdf   resume
```
