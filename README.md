# Portfolio

Static site (HTML/CSS/JS, no build step).

## Edit
- Projects and skills: `data.js`
- Text, email, LinkedIn: `index.html` (search for `your@email.com` and `your-handle`)
- Resume: drop `resume.pdf` in this folder

## Deploy (GitHub Pages)
1. On GitHub, create a **public** repo named `mouliiii21.github.io`
2. In this folder:
   git init
   git add .
   git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/mouliiii21/mouliiii21.github.io.git
   git push -u origin main
3. Repo Settings > Pages > Source: **Deploy from a branch** > `main` / `(root)` > Save
4. Live in ~1 minute at https://mouliiii21.github.io

## Update later
Edit files, then: git add . && git commit -m "Update" && git push
